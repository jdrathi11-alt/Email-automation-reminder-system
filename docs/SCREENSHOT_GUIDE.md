# Screenshot Guide

Capture the following for your GitHub portfolio:

1. Project folder structure
2. Sample contacts CSV
3. Sample reminders CSV
4. Email template files
5. Dry-run terminal output
6. Reminder schedule output
7. Log file showing successful/failed sends
8. Generated report CSV
9. GitHub repository preview
10. Final README preview

Keep screenshots in the `images/` folder. Do not include real emails, passwords, or private customer data.
